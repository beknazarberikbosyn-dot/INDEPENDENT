# INDEPENDENT — голосовой помощник для повседневной самостоятельности

Прототип сайта платформы, которая помогает пожилым людям решать бытовые задачи голосом — на казахском и русском — без изучения десятков приложений и без ожидания помощи родственников.

## Что есть в прототипе

- **Рабочее демо помощника** — можно говорить в микрофон (Web Speech API, лучше всего в Chrome) или писать текстом. Понимает запросы на русском и казахском и отвечает на языке пользователя, озвучивает ответы.
  - такси до привычных адресов (дом, поликлиника, дочь, базар) с подтверждением «да / нет»
  - маршрут на автобусе
  - продукты (в т.ч. «как обычно»), аптека, уборка, мастер (сантехник / электрик)
  - звонок близким, кнопка «Позвать человека» (оператор) и **SOS**
  - проверка недельного лимита расходов
- **Family Freedom Settings** — форма первичной настройки (адреса, экстренные контакты, лимит, согласия). Изменения сразу влияют на ответы помощника: например, если выключить «Сообщать близким при SOS», помощник не будет никого уведомлять.
- **Доступность**: переключатель языка РУС / ҚАЗ, три размера текста, режим высокого контраста, крупные кнопки, поддержка клавиатуры и `prefers-reduced-motion`.
- Разделы: как это работает, возможности, принцип INDEPENDENCE, уникальность, социальный эффект, форма для партнёров.

> Все заказы, звонки и оплаты в прототипе **имитируются** — реальные сервисы не вызываются.

## Запуск

Сборка не нужна — это статический сайт.

```bash
# просто открыть
open index.html

# или локальный сервер (нужен для микрофона в некоторых браузерах)
python3 -m http.server 8000
# → http://localhost:8000
```

Чтобы опубликовать: **Settings → Pages → Deploy from a branch → `main` / root**.

## Примеры фраз

| Русский | Қазақша |

| Вызови такси в поликлинику | Емханаға такси шақыр |
| Закажи продукты как обычно | Маған нан мен сүт керек |
| Как доехать до базара? | Базарға қалай барамын? |
| Течёт кран, нужен мастер | Кран ағып тұр |

## Структура

```
index.html   — разметка страницы
styles.css   — стили (адаптив, крупный текст, контраст)
i18n.js      — тексты интерфейса на русском и казахском
app.js       — логика: переключатели, распознавание речи, движок намерений, настройки семьи
```
