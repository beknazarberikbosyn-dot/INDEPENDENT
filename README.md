# INDEPENDENT — голосовой помощник для пожилых

Прототип мобильного веб-приложения. Пожилой человек говорит по-русски или по-казахски, а помощник сам открывает нужный раздел: такси, продукты, маршрут или бытовые услуги. Родственник один раз настраивает приложение и подстраховывает.

## Главные функции

1. **Распознавание речи RU / ҚАЗ.** Web Speech API (`ru-RU` / `kk-KZ`), язык ответа определяется автоматически: сказали по-казахски, и интерфейс переключится на ҚАЗ. Ответы озвучиваются. Если браузер не поддерживает микрофон, можно написать текстом.
2. **ИИ-помощник переводит в нужную категорию.** «Вызови такси домой» откроет экран такси с адресом и ценой. «Маған нан мен сүт керек» соберёт корзину продуктов, «Течёт кран» откроет услуги с сантехником, а «Как доехать до поликлиники?» покажет маршрут. На экране категории можно ответить голосом «да» или «нет».
3. **Сервисы:** такси, продукты с доставкой (корзина, «как обычно»), маршрут на автобусе и услуги (сантехник, электрик, уборка, мастер).
4. **Подстраховка от родственника.** Это экран «Режим родственника»:
   - экстренные контакты по порядку («Первый» / «Второй»). Кнопка «Позвать на помощь» звонит им по очереди, затем оператору, есть кнопка 103;
   - включение и выключение сервисов. Если сервис выключен, пожилой человек может одной кнопкой попросить родственника его включить;
   - месячный лимит. Заказ сверх лимита уходит родственнику на подтверждение;
   - журнал запросов. Заказы видны родственнику только с согласия пользователя.

> Заказы, звонки и одобрения в прототипе **имитируются**.

## Запуск

Сборка не нужна: это статический сайт.

```bash
python3 -m http.server 8000   # → http://localhost:8000 (микрофон лучше всего работает в Chrome)
```

## Структура

```
index.html  — экраны: главный, такси, продукты, маршрут, услуги, режим родственника
styles.css  — UI по макету (тёмно-зелёный / жёлтый / кремовый)
i18n.js     — статические тексты RU / KK
app.js      — распознавание речи, разбор запросов, сервисы, лимит и подстраховка
```
